# Security Policy

## Supported versions

Security fixes are supported for the current 1.x line.

| Version | Supported |
| --- | --- |
| 1.x | Yes |
| < 1.0 | No |

## Reporting a vulnerability

Please report suspected vulnerabilities through GitHub Security Advisories for
this repository. Avoid opening a public issue for security-sensitive details.

Maintainers aim to acknowledge reports within 48 hours, then provide follow-up
updates as the issue is triaged. Confirmed vulnerabilities will be fixed in a
patch release and documented in the changelog when disclosure is appropriate.
